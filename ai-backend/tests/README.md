# 回归测试与知识库基础修复验收

当前计划保持业务现状，不新增草稿或人工确认流程。后续最小 Harness 和实际 RAG 评估修复已加入同一测试目录，配置、边界及人工验收见 [../agent/README.md](../agent/README.md)。以下知识库范围和验收步骤继续有效。

## 本阶段范围

- 上传接口使用 Pydantic JSON 请求模型，支持 txt/md（无后缀按 txt），严格校验 Base64、UTF-8、文件名和单文件 1 MiB 上限。
- 向量写入、检索、读取和删除强制校验用户身份；文档读取/删除同时限定用户 ID 和文档 ID，过滤字符串中的引号、反斜杠使用 JSON 字符串转义。
- 删除前校验数据库归属。向量删除失败返回 503，保留元数据供重试，不再吞掉异常报告成功。
- SQLite 新增可空的 `documents.content` 保存新文档原文，避免通过重叠片段拼全文。初始化时自动补列，保留已有记录。
- 旧文档按历史固定 60 字重叠恢复，验证片段索引、重叠内容、片段数量、原文长度；无法验证时返回 409，提示重新上传。不猜测原文，不修改已有向量。
- 全文缓存键升级为 `kb:doc:v2:{user_id}:{doc_id}`，避免命中旧版重复拼接结果。读取缓存前先校验文档存在性及归属。
- Redis 连接、读写或失效异常不影响数据库主流程；损坏的 JSON 缓存按未命中处理。
- 文档预览使用 Vue 文本插值。聊天 Markdown 和技术文章展示使用 DOMPurify 白名单清洗；保留代码高亮、标题、列表、链接、图片和表格，不允许脚本、事件属性、内联样式、表单、iframe、SVG 和 MathML。
- 上传失败、删除失败、旧资料恢复失败会在前端展示错误提示。

不包含草稿发布、Agent 任务治理或 RAG 检索质量优化。

## 自动测试

从项目根目录执行（先安装项目 Python 依赖，并安装 `pytest`）：

```bash
python3 -m pip install pytest
python3 -m pytest ai-backend/tests -q

# 真实 Milvus Lite 集成测试：临时数据库 + 合成向量，无模型下载和网络调用
RUN_MILVUS_TESTS=1 python3 -m pytest ai-backend/tests -q

# 前端：安装依赖后运行安全测试及 Vue SFC 编译检查，不执行生产构建
npm --prefix frontend ci
npm --prefix frontend test
```

测试使用临时 SQLite、模拟鉴权/Redis/向量化，不读写开发数据库，不调用真实业务服务。可选集成测试会启动临时 Milvus Lite。前端测试使用 jsdom 检查清洗后的 DOM，以及改动页面的脚本和模板能否编译。

## 人工验收

1. 使用两个成员账号 A、B 登录。
2. A 上传一份超过 300 字的 UTF-8 Markdown；检查列表和全文，确认全文与原文一致、无重复段落。
3. B 尝试访问、删除 A 的文档 ID，应返回 404；A 的资料仍可查看、检索。
4. 上传非法 Base64、非 UTF-8、不支持后缀或超限文件，应被拒绝。
5. 上传含 `<img src=x onerror=alert(1)>` 的文档，预览只显示文本，不执行代码。
6. 在 AI 回复/文章展示测试恶意事件属性、`javascript:` 链接，确认被清除；正常代码高亮、链接与 OSS 图片仍显示。
7. 旧文档应恢复无重复全文；片段不全或长度不符时应提示重新上传。
8. 停止 Redis 后检查上传、列表、全文、删除仍可完成（日志会记录降级）。

部署前备份 SQLite 和 Milvus 数据；部署时重启 AI 服务，使自动补列生效，并更新前端依赖与发布产物。无需清空 Redis，旧全文缓存会自然过期。

## 已知边界 / 后续阶段

- SQLite 与 Milvus 没有共享事务。上传失败会尽力清理部分向量，但若清理也失败，仍可能留下孤立向量；尚未引入持久化补偿任务。向量删除成功后 SQLite 提交失败，也需要重试或后续修复机制。
- 文档列表缓存仍采用 TTL + 写后失效。失效失败后可能短暂展示旧列表；全文会重新校验数据库归属和存在性，不因旧缓存暴露已删除文档内容。
- 上传有单文件限制，但未加入总存储配额、入口请求体限制或全局向量化任务并发预算。大 JSON 仍需在反向代理层限制请求体大小。
- HTML 清洗是当前前端展示入口的防护，不等于 Java 发布接口已加入服务端清洗；服务端清洗仍属已知边界，不在本轮 Harness 范围。
- 自动测试未覆盖真实 Java 登录、真实 embedding 模型、LLM 或浏览器端完整联调。未执行生产构建。
